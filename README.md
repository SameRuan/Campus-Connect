鸿蒙校园通

基于 HarmonyOS ArkUI 开发的一站式校园助手小程序，覆盖校园社交、个人记账、音乐放松、个人中心等场景，为大学生提供便捷的校园生活服务。


## 项目简介

鸿蒙校园通采用 ArkUI 声明式 UI 与 ArkTS 语言开发，包含登录认证、校园帖子流、账本记账、音乐放松、个人中心等核心模块。用户可以在一个应用内完成发帖、查看校园动态、记录日常收支、听歌放松等操作。

## 功能模块

- **登录 / 注册**：账号密码登录、用户协议与隐私政策确认、注册与找回密码入口
- **首页 · 校园帖子**：校园帖子流，包含寻人启事、表白墙、失物招领、寻物启事等；支持查看“我发布的”
- **账本**：展示本月预算、已消费、剩余额度，支持刷新与快速记账入口
- **记账**：记录支出 / 收入，支持吃、穿、住、行、工资、兼职等分类，填写金额与备注后保存
- **放松**：音乐放松空间，首页轮播图、8 大分类歌单矩阵、随机激励文案
- **影视歌单**：展示指定分类下的歌曲列表，支持“播放全部”与单曲点击播放
- **歌曲详情**：沉浸式播放器，歌曲信息、封面、进度条、播放控制、歌词展示
- **我的**：用户信息、我的帖子、我喜欢的、设置、退出登录

## 技术栈

- **开发框架**：HarmonyOS ArkUI（声明式 UI）
- **编程语言**：ArkTS
- **核心组件**：
  - `List` + `LazyForEach`：高性能长列表渲染
  - `Swiper`：顶部轮播图
  - `Navigation` / `router`：页面路由与跳转
  - `AVPlayer`：音频播放
- **状态管理**：`@State`、`@Provide` / `@Consume`
- **开发工具**：DevEco Studio

## 本人负责模块：音乐放松

独立负责“放松”模块全链路开发，包含以下三个页面：

### 1. 放松主页

- 顶部轮播图，支持自动轮播
- 8 大分类歌单矩阵：影视、流行、英文、日文、说唱、国风国朝等
- 底部随机激励文案：如“加油”、“喝汤Time”、“爱上自己的那一天”等

### 2. 影视歌单页

- 展示该分类下的歌曲列表
- 支持“播放全部”
- 点击单曲进入歌曲详情页

### 3. 歌曲详情页

- 沉浸式播放器界面
- 展示歌曲名称、歌手、专辑封面
- 播放 / 暂停、上一首 / 下一首、进度条控制
- 歌词展示

### 技术亮点

- 使用 `List` + `LazyForEach` 渲染 64 首曲目，保证长列表滑动流畅
- 通过页面路由与状态管理实现歌单 ⇄ 播放器双向联动
- 解决多层级页面间的数据传递与同步问题
- 实现随机文案算法，增强产品情感化体验
